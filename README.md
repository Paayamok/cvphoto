## 本地启动

```sh
git clone https://github.com/Paayamok/cvphoto.git
cd 'cvphoto/(PY)FuShengCe'
./gradlew :app:assembleDebug
```

需要 JDK 17、Android SDK 35。也可使用 Android Studio 打开 `(PY)FuShengCe` 目录。

本仓库仅交付项目源码、必要资源和接手文档；不包含测试材料、本机环境和构建输出。正式 3D 视觉与后续智能功能仍待开发。
