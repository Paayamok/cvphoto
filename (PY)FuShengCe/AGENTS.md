## 当前交付与开发范围

当前仓库是 `Paayamok/cvphoto`，`main` 为框架交付入口。先读 `README.md` 和 `HANDOFF.md`。本轮交付 12 模块底座，后续功能由接手者按用户要求开发；不恢复旧账户的自动开发任务。

模块职责、依赖方向与扩展入口见 `README.md`。保留现有功能、数据库迁移与本机元数据格式，不以架构整理为由清理用户数据或重做视觉资产。视觉与 3D 成品在最终验收前保持 DRAFT；先按两张冻结母版完成多视图，再做模型、动作与接入。

## 3D 与动作硬规则

- 运行技术：沿用已验证的 SceneView 2.3.0 + Compose 状态机思路；正式接入前重新做许可证与兼容验证。
- 正式模型必须本地化，禁止远程 URL。
- 大人物态和桌宠态必须是同一模型、骨骼、材质、贴图与身份，只允许尺度、位置、动作和受控特效变化。
- 必须实现并验收：待机、呼吸/眨眼、接令、蓄势、缩小、落地、走/跑、任务待机、生活境翻册/取照/理影、行事境展卷/书写/盖印/排任务、完成、未找到、异常、返回、恢复。
- 缩放与位移必须连续；角色不得瞬移、换脸、换装、换材质或在任务期间消失。
- 首页主题始终是照片管理；人物是 AI 助手，办事时近前，阅册时退景，不得长期遮挡照片。

## Git 与验收

- 当前交付入口：`Paayamok/cvphoto` 的 `main`。不要操作旧仓库的 Draft PR #6。
- 每次提交包含可核对的产物与验证记录；功能阶段可连续推进，视觉阶段按顺序自检。
- Git 优先 SSH；失败一次后立即切换已连接 GitHub 官方能力。
- 未经用户最终统一验收的设计只能标记为 DRAFT，不能写成“已定稿”。
