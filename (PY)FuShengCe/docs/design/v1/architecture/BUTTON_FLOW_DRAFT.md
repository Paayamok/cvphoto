# 浮生册 V1 按钮与跳转关系草案

状态：待确认（非正式开发基准）

说明：
- 以 `SCREEN_MAP.md` 的 S01–S47 为页面基准。
- 本文件只保留当前最新版草案，不创建 v2/v3/v4。
- 本轮目标是检查每个入口、按钮、返回路径、操作结果和高风险确认是否闭环。
- 系统级权限弹窗、系统分享面板、系统相机/照片选择器不单独计为 App 页面。

## 全局规则

1. 所有主要页面均可唤起 S09「一语相托」；完成后回到发起页面或进入对应结果页。
2. 顶部返回默认返回上一级；首页层级不显示返回。
3. 高风险操作（永久删除、证件删除、清除索引等）必须二次确认。
4. 普通整理动作优先支持撤销。
5. 生活境与行事境共享照片库、人物、事件、卷册和搜索底层数据。
6. 任何照片缩略图点击后默认进入 S29；任何视频缩略图点击后进入 S30。
7. 人物卡点击进入 S19；事件卡点击进入 S34；卷册卡点击进入 S12；工作事项卡点击进入 S39。

## 全局弹窗与状态

- 删除确认：普通照片删除前确认。
- 证件删除强提醒：明确提示证件类照片风险。
- 永久删除确认：不可撤销，必须二次确认。
- 压缩确认：说明节省空间、可恢复策略。
- 压缩恢复确认：说明恢复所需空间。
- 撤销提示：整理/移动/删除后的短时可撤销入口。
- 权限被拒/部分照片权限：提供“继续受限使用”和“去设置”。
- 空内容/读取失败/媒体不存在/存储不足：提供明确恢复动作。
- 网络/云端不可用：仅未来云端能力启用时出现。
